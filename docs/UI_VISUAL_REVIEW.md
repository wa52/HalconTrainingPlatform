# UI 视觉审查与改进

## 图像移除功能审查（2026-10-19）

目标：在导入文件夹后的图像筛选流程中剔除不需要的图片，保留原图。布局沿用当前浅色令牌和排版，只在图像列表标题旁增加一个图片减号图标，不在工具栏或缩略图中重复入口，也不与删除检测框混用。确认窗口显示路径、保留原图及后续训练影响，默认取消；移除后自动切换下一图，最后一张时清空选择并禁用入口。

Release 构建无警告/错误；数据层冒烟与 15 项隔离原生检查通过，覆盖取消、保存恢复、两种窗口尺寸、缩略图与数量、最后一张、重新扫描、预测/导出/合并训练排除、原图字节不变及写入失败。完整 UI 策略回归 59 项通过。训练算法未修改，本轮没有新 GPU 训练或 mAP 验收；其他系统 DPI 未复测。

七维自评（当前环境）：协调性 4（复用列表标题栏）、层次 4（唯一低频次级入口）、排版 4（完整路径换行/滚动）、组件 4（共用图标与提示）、空间 4（保留原图最小视口）、交互 4（默认取消、状态与选择同步）、完成度 4（原生与数据检查有证据，多 DPI 和批量移除尚未覆盖）。分数仅用于诊断。

## 设计分析（2026-10-19）

用户为 Windows 工业视觉工程师，常用鼠标、键盘，在文件夹标注、修改训练参数和检查结果之间切换。首要路径为选择数据 → 确认标注 → 训练 → 原图测试。四个训练参数持续可见，不新增业务步骤或模型输出。

参考 [MVTec Deep Learning Tool 工作流](https://www.mvtec.com/products/deep-learning-tool/features-workflows)：借鉴按数据准备、训练和评估组织工作，以及训练参数与实时反馈相邻的原则，不复制其页面或引入新的顶层导航。

本轮具体问题：此前三页导航仅有图标，主要训练按钮和高级参数标题也需要悬停才能理解；空闲监控保留大面积白色面板；无图时黑色图像区让初次使用像设备故障。优先修复入口和空状态，其次统一组件状态。

布局决策：保留三个文字加图标的顶层页面；关键训练/确认操作保留文字，文件管理和次级工具仍为图标；折叠区域保留短标题。训练前左侧参数、右侧紧凑说明，训练后右侧恢复伸展监控；图像只在有数据时成为视觉中心，空状态给出下一步，不显示假曲线。

令牌沿用本产品浅色主题：背景 #F4F5F7、面板 #FFFFFF、正文 #20262E、辅助 #69737E、线条 #DDE1E6、主蓝 #2464A2。中文 Microsoft YaHei UI（22/16/14/12），数值 Consolas，8/12/16/24 间距；不添加装饰阴影、渐变或新的组件库。
