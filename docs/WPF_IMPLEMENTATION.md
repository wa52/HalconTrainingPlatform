# 原生 WPF 工作流

界面保留总览、数据集、训练、模型管理四页。布局使用既有白色面板、蓝色主操作、深色图像视口，常用参数常显，高级参数折叠。Views仅负责绑定和HSmartWindowControlWPF显示；ViewModel管理交互状态；Application协调独立Worker与Persistence归档，不经HTTP、Node或WebView。

数据流程：原路径读取字典→统一固定种子/分组划分→按任务选择项目内基础模型→保存配置与作业状态→独立进程训练→独立进程评估→更新manifest与校验和→模型库登记→原图批量测试→原图尺寸掩膜或分类类别/置信度显示和持久化。源字典/基础模型不改写。用户取消时终止独立Worker，记录Interrupted，保留产物且不发布为已验证模型；不冒充可断点续训。

图像生命周期：算法句柄仅在Worker；显示句柄仅在App的显示控件，切换图片、卸载控件时释放。原图及预测掩膜以文件路径传递，HSmartWindowControlWPF显示原图和青色预测轮廓。测试结果保留于results/tests，可在重启后从JSON恢复。

当前已实现且有真实训练功能验证的适配器是图像分类和语义分割。其他任务读取与基础模型识别可用，未验证的训练/测试任务明确提示不可执行。参数包含尺寸、Batch、Epoch、学习率、随机种子和划分比例；默认70/15/15。
