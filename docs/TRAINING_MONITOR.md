# WPF 实时训练监控

以本机HALCON24.11附带的 `Segmentation/segment_pill_defects_deep_learning_2_train.hdev` 和 `procedures/dl/dl_training.hdpl` 的训练展示流程为参考：平滑Loss、按Epoch/Iteration显示进度、定期验证和验证图像预览。只借鉴信息组织；界面由WPF绘制，算法Worker不调用HDevelop显示函数。

训练每批上报实际batch loss、最近约1000训练样本的平滑loss、学习率和迭代耗时。WPF提供独立Loss与验证集mIoU曲线、当前/最佳验证mIoU、Epoch、总迭代、已用时间及估算剩余。剩余时间用近期批次耗时中位数估算，只计训练批次，不含之后的验证和独立评估，界面明确注明。

验证间隔默认1轮，可在高级参数修改；最后一轮始终验证。每个验证轮次使用完整验证集和当前内存中的模型，保持训练Batch大小，不调用训练算子，不读取测试集。保存固定验证样本的原图、人工真值、预测掩膜到运行目录training-preview/epoch_xxxx，坐标还原为原图尺寸；可在训练面板展开对照。

每轮写入epoch_metrics.jsonl，原始批次事件写入training.log，归档时纳入校验和。最终仍独立重载模型，评估验证/测试集合；训练过程的验证指标不会冒充测试集指标。旧模型包不改写。

图表保留真实采样点，长运行时稀疏保留显示点以限制绘制开销，完整数据保留在日志。最终状态冻结计时；初始化/验证/独立评估阶段显示忙碌进度，不捏造指标。现支持图像分类和语义分割：分类使用验证准确率和真实/预测类别、置信度，语义分割使用mIoU及掩膜；训练曲线均来自真实批次。
