# UI 重构准则：简洁、有效、清晰

以操作效率和首次使用成功率为最高标准。唯一主流程是：选择数据集 → 开始训练 → 查看结果 → 测试模型。

仅保留数据集、训练、模型三个顶层页面。当前任务、任务类型、环境状态集中在顶部；环境检查的具体结论有依据，尚未验证时不得显示“环境正常”。

数据集页以大图和标注为中心，侧栏提供图片列表、类别和数据检查。选择后明确提示是否可以训练及阻塞原因，并提供下一步入口。训练页在开始前展开参数；开始后自动收起参数，扩大监控区域，停止操作始终可见；完成后突出查看模型入口。模型页保持模型选择与图像测试在同一屏，评估摘要直接显示，低频指标和显示设置折叠。

色彩：白色 #FFFFFF，浅灰背景 #F4F5F7，正文 #20262E，次要文字 #69737E，边线 #DDE1E6，唯一主蓝 #2464A2。成功、警告和失败色仅用于状态。字号：正文14、辅助12、标题22；中文 Microsoft YaHei UI，数值 Consolas。间距统一8/12/16/24，不用阴影、渐变和装饰图标。主要区域最多一个主按钮。

布局：顶部状态栏 + 横向三页导航，内容使用分栏和细分隔线，避免重复卡片。以状态驱动的参数收起/监控展开作为唯一突出交互，满足工业操作而不追求装饰效果。

验收覆盖空状态、错误参数及原因、全部样本浏览、标注显示、默认折叠、真实训练焦点切换、完成后查看模型、原图测试、停止和重载。分类、语义分割均回归；证据在本机 artifacts 下，不随源码提交。


训练页补充准则（2026-10-16）：训练前常显且可直接修改图像尺寸、Batch、Epoch、学习率四项。顶部显示实际数据集信息；比例、真实集合数量与基础模型保持可见。修改划分比例或种子后，数量标为待更新，更新真实划分后才允许训练。训练中收窄参数区并展示含学习率的锁定摘要，停止/完成后恢复四项编辑。仅已实现的任务设置可操作，分类/分割分别显示各自类别与验证指标，不展示未实现的忽略类别、类别权重输入框。
