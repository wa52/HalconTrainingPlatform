# UI 重构准则：简洁、有效、清晰

以操作效率和首次使用成功率为最高标准。唯一主流程是：选择数据集 → 开始训练 → 查看结果 → 测试模型。

仅保留数据集、训练、模型三个顶层页面。当前任务、任务类型、环境状态集中在顶部；环境检查的具体结论有依据，尚未验证时不得显示“环境正常”。

数据集页以大图和标注为中心，侧栏提供图片列表、类别和数据检查。选择后明确提示是否可以训练及阻塞原因，通过训练页标签进入下一步。训练页在开始前展开参数；开始后自动收起参数，扩大监控区域，停止操作始终可见；完成后通过模型页标签查看结果。模型页保持模型选择与图像测试在同一屏，评估摘要直接显示，低频指标和显示设置折叠。页面导航不另放重复的按钮。

色彩：白色 #FFFFFF，浅灰背景 #F4F5F7，正文 #20262E，次要文字 #69737E，边线 #DDE1E6，唯一主蓝 #2464A2。成功、警告和失败色仅用于状态。字号：正文14、辅助12、标题22；中文 Microsoft YaHei UI，数值 Consolas。间距统一8/12/16/24，不用阴影、渐变和装饰图标。主要区域最多一个主按钮。

布局：顶部状态栏 + 横向三页导航，内容使用分栏和细分隔线，避免重复卡片。以状态驱动的参数收起/监控展开作为唯一突出交互，满足工业操作而不追求装饰效果。

验收覆盖空状态、错误参数及原因、全部样本浏览、标注显示、默认折叠、真实训练焦点切换、完成后查看模型、原图测试、停止和重载。分类、语义分割均回归；证据在本机 artifacts 下，不随源码提交。


训练页补充准则（2026-10-16）：训练前常显且可直接修改图像尺寸、Batch、Epoch、学习率四项。顶部显示实际数据集信息；比例、真实集合数量与基础模型保持可见。修改划分比例或种子后，数量标为待更新，更新真实划分后才允许训练。训练中收窄参数区并展示含学习率的锁定摘要，停止/完成后恢复四项编辑。仅已实现的任务设置可操作，分类/分割分别显示各自类别与验证指标，不展示未实现的忽略类别、类别权重输入框。

用户级 MD 规则补充（2026-10-19）：

- 操作采用共用矢量图标；导航、主要训练/确认/测试操作和折叠分区保留必要中文标题，文件/文件夹选择与次级操作仍为图标。不能让用户必须悬停才能理解主要流程。鼠标停留 1.5 秒显示中文功能说明，移动到另一控件时重新等待；动态、禁用控件和独立窗口一致，保留可访问名称、快捷键、焦点和选中状态。
- 软件名称固定为「HALCON 训练平台」，不修改程序文件名和桌面入口名称。参数、类别、计数、图像名称、表格字段和结果数据继续保留文字。缩略图是可选择的数据项，保留图像和名称。
- 合并 HDICT 导出仅保留顶部入口，划分更新仅保留划分摘要旁入口。Ctrl+1/2/3 切换三页；Ctrl+O 选择数据集，Ctrl+Shift+O 选择图片文件夹；Ctrl+S 按当前页面保存参数或标注草稿，运行期间不触发修改。
- 长名称省略并提供完整提示，日志和低频区域可滚动。分栏调整保留最小宽度；低频区域全部展开时允许工作区滚动，不能挤掉原图或操作。独立类别输入窗口按内容确定高度；类别列表换行并滚动。
- 原图中的类别标签使用 WPF 显示层避让；长标签限制显示宽度，完整类别仍在类别/坐标表中可查。不改变模型输出、原始框坐标或人工标签。
- 显式验证入口 `--validate-ui-policy --validation-output <目录>`：在独立 `HALCON_TRAINING_HOME` 检查图标、可访问名称、延时设置、重复入口、两种窗口尺寸、长类别、分栏和模式切换；不训练。追加 `--manual-ui-check` 保留实际类别输入窗口，供真实鼠标提示时序检查；悬停事件写入验证目录。Esc 取消类别窗口后可继续检查主界面快捷键，Alt+F4 结束检查并释放资源。
- 界面交付必须重新截取正在运行的目标窗口，并确认没有混入其他应用。优先发送手机可显示的真实图片附件；通道附件不可用时，保存到 `docs/screenshots/`，提交推送并核对远端后提供带提交 SHA 的图片地址。明确说明编辑界面或真实运行结果，不以设计图、生成图或旧图替代。

通用 UI/UX 规范执行补充：先分析用户、任务和布局，再实现；按 `UI_UX_STANDARD.md` 进行七维审美诊断与迭代，记录在 `UI_VISUAL_REVIEW.md`。数据集与模型无结果时使用紧凑指引，不预留空白大图；训练监控空闲时按内容收缩，真实执行或已有指标时恢复展开。显示层状态检查与真实 GPU 训练应分别报告，多 DPI 未验证时不能声称通过。
